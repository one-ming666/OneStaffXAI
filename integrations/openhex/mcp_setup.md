# 可选 MCP 工具连接

整理日期：2026-09-19。

服务提供 `/mcp` JSON-RPC 接口，工具包括资料检索、任务状态、表格分析与 Word 草稿生成。只支持当前实现的 HTTP 请求模式，不能据此声称兼容所有 MCP 传输方式。

配置 OpenHex 的 MCP 连接前，先将服务部署到可访问的 HTTPS 域名。连接地址为 `https://你的域名/mcp`；Authorization 为 `Bearer <MCP_TOKEN>`。令牌可由进程环境变量指定，否则首次启动在 data 中生成。不可将它写入公开前端。

每次调用还必须携带本站“团队任务 → OpenHex 工具授权”取得的 capability。该凭证限定到当前任务与空间，30分钟到期。传输令牌与任务凭证缺一不可。生成的工具文档标注为未监察草稿，不能替代任务验收。

如果设置 PUBLIC_URL，文档工具可返回30分钟有效的下载链接；否则在本站成果中心下载。链接到期需重新取得授权，不能手动拼接内部文件路径。
