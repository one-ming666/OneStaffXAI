# 验证报告

验证日期：2026-09-19。运行环境：Linux，Node.js 24；浏览器自动化使用 Chromium。所有模型协议测试使用本地夹具，没有消耗用户的云端密钥。

## 通过的检查

- 源码检查：33个后端、前端及HTML内联脚本语法检查通过。
- 离线测试：53项通过，增加400响应中issues优先展示、错误脱敏和请求体边界检查。
- HTTP集成测试：22项通过，覆盖访客/管理员鉴权、上传下载一致性、生成Word/PDF/PPT、草稿导出、节点正文访问、消息导出权限、语音偏好持久化、团队状态与监察；增加员工结果隔离、总监监察免Agent ID、400字段原因贯通、配置导入预览及一次性确认，以及监察与后续建议并行执行。
- 文档内容：中文长段落DOCX/PDF/PPTX实际生成后重读，核对900次重复内容及末尾标记，验证分页换行后正文未截断。不是仅检查扩展名或文件头。
- 浏览器页面：360×800、390×844、768×1024、1440×1000四种视口，各检查11个页面，共44组路由检查；确认没有横向溢出、滚轮能够滚动目标容器。
- 浏览器操作：保存并重载语速音量、设备诊断弹窗、服务控制台滚动、团队节点正文查看、草稿Word下载、聊天PDF下载、后续问题填入输入框、移动侧栏导航。
- 配置交互：四种视口均验证模型测试不跳回顶部、批量员工测试遇错继续、各员工独立结果与具体字段提示；总监监察不存在Agent ID输入框。补测JSON、DOCX、文字PDF导入和无效文档拒绝。
- 依赖：OpenHex SDK 0.5.1；通过锁定ExcelJS下的uuid 11.1.1与PptxGenJS下的image-size 2.0.4处理审计告警。更新后文档生成、解析与全部74项测试通过，npm audit --omit=dev在验证时报告0项已知漏洞，这不是无漏洞保证。
- 解锁：手机和平板检查密码面板宽度与页面布局；模拟摄像头权限拒绝，确认具体错误提示；实际点击1314验证密码入口成功；另从首页启动入场动画，在嵌入式密码页输入1314，确认自动进入工作台引导页。

## 不能由本次本地验证替代的项目

1. 用户真实OpenHex个人Key、账户默认工作区、Agent工具权限与额度。个人Key不换工作区令牌、原文件parts、会话接续、不同访客隔离等已由本地协议验证，但不是生产账号实测。
2. 用户模型服务的真实模型ID、语音ASR/TTS、天气和搜索服务。分发包不带任何用户端点或密钥；管理员必须在自己的控制台填写实际配置。
3. 实体手机与平板的触摸键盘、系统音量策略、真实摄像头、麦克风和驱动。Chromium视口验证不等于iOS Safari或每款安卓设备测试。
4. MediaPipe CDN和模型资源在实际网络中的可达性。失败有提示与密码入口，未将本地模拟权限错误称为真实手势识别测试。
5. Word/PowerPoint各版本的视觉一致性。本次验证了格式结构和中文正文完整性，未在用户本机Office逐页打开检查；本地PPT是文本分页导出，不是设计成稿。

## 补充复查

聊天滚动回归：构造一条90段长回复和8条后续消息，修复前实际触发“滚轮无法滚动长聊天”断言失败。原因是消息列表继承flex收缩，又使用contain: content裁剪溢出正文。修复仅取消消息列表收缩和内容裁剪，使外层conversation负责滚动；新增滚轮向下、末条消息可达、滚轮返回历史的浏览器断言。此项验证补足此前单条短消息导出测试未覆盖的缺口。

弹窗标题与正文分离，正文是独立滚动区，关闭按钮不再覆盖内容；保留配置重绘前的正文滚动位置。四种视口补测400像素可用高度，验证键盘滚到底部、标题不遮挡正文、弹窗不越出屏幕、关闭按钮可点击；同时复查鼠标滚轮及配置测试后的滚动位置。

正文流式返回保持原实现；正文后的独立监察和总监下一步建议改为并行，仍等两项处理结束后保存最终状态。集成夹具在监察返回前检查建议请求已启动，并核对两项结果均保留。这减少串行收尾等待，不代表生产OpenHex首字耗时变快；没有真实账号延迟基准，不宣称固定提速百分比。

手势引擎加载和逐帧识别的超时计时器在请求结束后立即清理；旧识别会话报错时不再停止新会话的摄像头。配置测试新增滚动位置保持、批量测试遇错继续、对应卡片展示字段原因的浏览器检查。测试夹具模拟的400与成功结果不代表用户生产账号实测。
