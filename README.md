# OneStaff X AI

发布日期：2026-09-19　发布标识：2026.9.19

多模态数字员工工作空间。总监理解目标，专业员工执行，监察者独立复核，成果以可下载文件交付。个人聊天和团队任务分别保存，附件、任务与成果按访客空间隔离。

弹窗采用固定标题区和独立正文滚动区，窄屏及较低窗口中可滚动到全部内容和底部按钮，配置测试后保留当前位置。正文持续流式显示；正文完成后的监察与总监后续建议并行处理，减少收尾等待。实际首字速度仍取决于上游模型和网络，页面显示首字及本轮耗时供排查。

## 从零启动

1. 安装 Node.js 22.13 或更高版本（支持内置 SQLite）。Windows 解压整个文件夹到任意普通目录，例如 `C:\OneStaffXAI`，不要在压缩包里直接运行。
2. 双击 `START_ONESTAFF.cmd`。首次启动会安装锁定的依赖；需要联网访问 npm。启动窗口保持打开。
3. 浏览器访问 `http://localhost:3000`。密码入口的演示密码为 **1314**；手势入口需要允许摄像头。手势不是身份认证，密码也只是入口交互。服务端的访客会话和管理员口令负责实际权限隔离。
4. 选择形象、填写空间名称。进入“设置与帮助 → 管理员配置”，打开 `data/admin-password.txt`，复制本机首次启动生成的口令。
5. 配置总监、监察者的模型服务；填写 OpenHex 个人 API Key 和专业员工 Agent ID，保存后点击“一键测试全部员工”。总监与监察者始终使用兼容模型接口，无需 Agent ID。

配置页面支持上传 TXT、MD、JSON、DOCX 和文字 PDF（2 MB以内，提取文本64 KB以内，PDF最多20页）。先下载页面里的配置模板，填写真实配置并删除不用的完整分区；Word/PDF沿用同样的标题和分行结构，扫描图片不支持。JSON使用配置对象字段名，可提供 `providers`、`defaultProvider`、`reviewProvider`、`openhex` 等字段；模型数组会整体替换。导入在本站后端本地解析，不把密钥文档交给模型。先预览再确认，未确认不改配置；导入不代表接口已通过测试。

员工测试使用已保存配置，按当前通道和单人模型覆盖进行真实连接测试；依次执行，失败不会阻止下一位，总监和监察按指定基座测试。结果保存在各自员工名下，重新打开配置页可查看；配置变更后旧结果清除。批量测试会使用真实调用额度；“停止后续测试”不会撤销当前已提交的请求。

测试结果留在对应卡片，不自动滚回页首。失败显示 HTTP 状态、可用的字段路径与处理建议。OpenHex 的 `400 Validation error` 优先显示 `issues[].path/message`，不会只显示笼统错误，也不会输出原始请求体、密钥或文档内容。若上游没有提供字段信息，页面会保留现有错误证据，不猜测具体原因。

升级已有实例：先备份原目录，停止旧服务，将新包解压到独立目录；需要保留原配置和记录时，将原来的整个 `data` 目录复制到新目录（包含数据库和加密密钥），按需保留原 `.env`，然后启动新服务。不要同时运行两个实例写同一数据库。执行 `npm ci` 安装锁定依赖；本次SDK为0.5.1。浏览器按 Ctrl+F5 加载新界面。旧 `.env` 中同名变量优先于网页配置，改动后需重启。

Mac / Linux 在项目目录执行：

```bash
npm ci --ignore-scripts
npm start
```

默认监听 `127.0.0.1:3000`。关闭启动窗口或关机后，服务停止；下次双击启动脚本即可，`data` 中的内容会保留。不要直接双击 `public/app.html`，它需要后端服务。

## 手机、平板与部署

手机和平板使用同一组功能，改为单列内容、底部导航和抽屉菜单。摄像头和麦克风要求 HTTPS 或本机 localhost；手机访问电脑的 HTTP 局域网 IP 通常不满足浏览器安全条件。

部署到已配置 HTTPS 的服务器时，设置进程环境变量：`HOST=0.0.0.0`、`NODE_ENV=production`、`PUBLIC_URL=https://你的域名`、`TRUST_PROXY=1`。只有在受信任反向代理后才设置 TRUST_PROXY。反向代理参考 `deploy/nginx.conf.example`，必须关闭响应缓冲以支持流式聊天。公开部署需妥善保管管理员口令。Docker 方式见 `docker-compose.yml`。

包中不包含真实 `.env`、数据库、口令、密钥、日志、Git 文件或 node_modules。`.env.example` 仅为无凭据的配置模板，可选择复制使用。运行数据默认写入 `data`，备份必须包含数据库与 `master.key`；丢失加密主密钥后无法读取已保存的服务密钥。

## 本次 OpenHex Agent 设计思路

运行栈为Node.js 22.13以上、Express、SQLite和原生浏览器界面，不需要单独启动前端构建服务。错误诊断在后端统一脱敏；文件配置本地解析；模型与员工测试使用同一生产调用路径。依赖锁定版本随包交付，文档库的安全依赖覆盖由`package.json`中的`overrides`管理，并随文件生成测试一起验证。

### 1. 按职责分工

总监负责理解目标、规划步骤、汇总正文和建议下一步。专业员工承担研究、分析、文案、设计和代码任务。监察者独立读取需求、可见依据和结果，检查覆盖、矛盾与未经证实的完成声明。它不能证明不可见的远端内部操作已经正确执行，也不承担安全认证。

普通聊天与团队任务是两条独立链路。总监聊天直接回答，结束后独立监察；开启主动跟进时，再生成最多两个与当前问题相关的后续问题建议。点击建议只填入输入框，用户确认后才发送。此功能增加一次总监模型调用，可在设置关闭。关闭网页后不会自动继续对话或主动发消息。

团队任务遵循：需求 → 计划 → 用户确认 → 按依赖顺序执行 → 汇总 → 独立监察 → 文件交付 → 用户修订。节点正文单独持久化，运行中也能查看草稿。失败、取消和监察不通过保留已有内容，修订是明确的新任务，不把草稿标成已验收成果。

### 2. 个人 Key 与工作区 Key 明确分开

默认使用 `authMode=personal`。个人 API Key 直接交给 `OpenhexClient`；SDK 使用该 Key 对应的默认工作区，不调用 Workspace 的 whoami、访客换票或成员接口。此模式不要求填写工作区 slug。不能将 Agent 分享链接误填为 API Base URL 或 Agent ID。

只有用户明确选择 `authMode=workspace` 时，才使用 Workspace Key 创建访客会话并取得成员令牌。两种凭据不能混用。后端保存凭据并进行加密，普通访客前端不会收到密钥。

同一空间、同一员工的聊天继续使用已保存的 conversationId；新聊天创建独立会话。配置变更会改变绑定指纹，阻止用新身份续接旧输出。具体 Agent 工具、第三方账号授权与额度仍由 OpenHex 管理。

### 3. 原文件传输与恢复

OpenHex 员工收到的是用户本轮显式选择的原文件，使用 SDK 上传后产生的附件 part；重复上传缓存按空间、Agent、文件摘要和对话范围隔离。上传失败不会悄悄转成无附件问题。

兼容模型通道使用本地文档文字片段和支持的图片输入，不声称读取了远端原文件。知识库仅在用户开启时按关键词取片段；它是轻量检索，并非向量数据库或完整语义 RAG。

每轮有唯一请求 ID。平台已经受理的请求不因网页断网而自动重发。流中断保存 conversationId、游标与已收到正文；恢复只继续接收。服务器重启会标记中断，用户核对后再决定下一步。取消停止后续处理，但不承诺撤销平台已经执行的操作。

### 4. 文件与交付闭环

- 上传：单文件20 MB，每轮最多8份、合计64 MB，空间总量256 MB；支持 PDF、DOCX、XLSX、PPTX、文本与常见图片。
- 解析：Office/PDF 通过受限后台工作线程解析；PPTX 提取幻灯片文字。扫描 PDF 和图片不做本地 OCR。原文件始终保留。
- 生成：聊天回复和团队正文支持 DOCX、PDF、PPTX、Markdown；团队支持 XLSX。未通过监察的输出标注“待核验草稿”，仍可下载检查。
- 完整性：PPT按段落长度拆页，避免单段长文被静默截断；PDF 中文导出需要可用的中文字体：可通过 `PDF_FONT` 指定本机字体，Windows/Linux 也会尝试常见系统字体路径；Docker 镜像会安装 Noto CJK。
- 下载：本地文件与远端成果均检查空间所有权；远端输出仅使用服务端记录的路径。错误显示在页面，不直接跳到一页 JSON。远端输出下载上限50 MB，超限需到平台处理。
- 格式边界：本地 DOCX/PPTX 是正文排版与分页导出，不能等同于专业排版设计。模型输出、原始附件与独立监察结论仍需按使用场景核对。

### 5. 交互与设备能力

界面滚动分为页面、聊天记录与弹窗三种明确容器；移动端改为单列与底部导航。聊天气泡支持长段落换行，流式渲染按浏览器帧合并，查看上文时不强制滚回底部。

语音速度范围0.5–2倍、音量0–100%，按空间保存。服务器 TTS 通过播放器调节速度与音量；浏览器朗读使用系统语音参数。部分移动浏览器实际音量由系统控制。权限被拒绝、硬件未连接、设备占用、连接不安全和引擎加载失败分别给出可操作提示。

网络图标表示浏览器联网状态；能够识别连接类型时显示 Wi-Fi。↓ 显示本站接收速率：流式聊天按收到的字节累计，其余资源在完成时按浏览器 Resource Timing 统计。它不是整台电脑的实时流量、上传速度或运营商带宽；无传输时显示零，缓存命中不冒充网络流量。

## 检查和验收

```bash
npm run check
npm test
```

浏览器检查需要额外安装 Playwright 与 Chromium：

```bash
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

浏览器测试自行启动临时服务和访客空间，不调用付费模型。实际测试范围及结果见 `docs/VALIDATION.md`。云端 Key、真实 Agent 权限、实际手机硬件与摄像头/麦克风驱动需要在部署环境逐项测试，不以本地协议夹具冒充真实云端验收。
