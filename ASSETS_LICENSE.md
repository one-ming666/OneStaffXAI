## Fonts

The GitHub source release does not bundle font binaries. PDF generation supports a locally installed Chinese font or a path provided through the `PDF_FONT` environment variable. `server/fonts/OFL.txt` is retained as a license/reference record for Noto Sans SC; obtain font software from its official source if you choose to use it.
