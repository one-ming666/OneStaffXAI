# Contributing

Contributions are welcome when they are reproducible and do not include private data or credentials.

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm ci`.
3. Run `npm run check` and the relevant tests before opening a pull request.
4. Keep `.env`, `data/`, generated databases, uploads, keys, logs, and local diagnostics out of commits.
5. For new media/assets, document the source and redistribution license in `THIRD_PARTY.md` or the appropriate provenance file.
6. Describe what changed, why it changed, and how it was tested.

By submitting a contribution, you agree that your code contribution may be distributed under the repository's Apache-2.0 license unless a different license is explicitly agreed for a specific file.
